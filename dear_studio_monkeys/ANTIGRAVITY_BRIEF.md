# Antigravity Brief: Dear Studio Monkeys

## Project Overview
A standalone personal introduction page from **Dinesh A** directed to the Studio Monkeys team. Dinesh is a multidisciplinary visual designer with a background in Fine Arts, branding, visual communication, animation, UX, and game design (M.Des from NID Bengaluru).

## Key Objectives
1. **Brand First**: Frame branding and visual communication as Dinesh's core discipline, with game design situated naturally under Adreno Monkeys.
2. **Design Language**: Follow the Studio Monkeys visual language (warm paper `#FEFAF0`, bold yellow `#FFC82B`, ink `#000000`, rust `#C94001`, editorial grid, restrained motion, dotted paper texture).
3. **Hero Typography**: Large, calm, centered, high-contrast serif headline inspired by the Studio Monkeys reference homepage.
4. **Real Instagram Embeds**: Embed 4 specific Instagram reels (Pacha Perundhu, Firangipani, Kusu Potangae, One Piece) as independent visual studies with stable layout and fallback links.
5. **Real Work Showcase**:
   - UPSC logo project (team contribution, illustrated with official asset).
   - KVIC visual assets exploration.
   - Handcrafted YouTube thumbnail posters for Kaber Vasuki's music releases (Oozhi, Frangipani, Unakkum Enna Pudichirka).
6. **Ecosystem Alignment**: Clear, distinct contribution angles for Studio Monkeys, Adreno Monkeys, Meta Monkeys, Otaku Monkeys, and Temple Monkeys.
7. **Strict Em Dash Rule**: Absolutely zero Unicode em dashes (U+2014) or encoded dash sequences in any content, titles, metadata, links, or CSS.
