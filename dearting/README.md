# Ting Senior Visualiser Portfolio

Open `index.html` in a browser, or serve this folder using a local web server.

## Product gallery

The Product Visualisation section contains one continuous horizontal carousel with all 14 supplied product, workstation, feature and material images. Image frames share one height while each slide width follows its image aspect ratio. The carousel moves automatically and supports pause/resume, mouse wheel, trackpad, pointer dragging, touch scrolling and keyboard navigation.

The page suppresses the browser context menu, as requested. Automatic movement respects the visitor's reduced-motion preference.

## Files

- `index.html` - page markup
- `styles.css` - site and component styling
- `script.js` - section reveals, Instagram processing and carousel interactions
- `assets/` - supplied thumbnails, product renders, UPSC visual and résumé PDF

Keep the `assets` folder beside the HTML, CSS and JavaScript files.
