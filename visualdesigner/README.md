# Dinesh A — Visual Designer & Visualiser Portfolio

A company-independent portfolio template built from the supplied portfolio project.

## Run locally
Open `index.html` in a browser. For best results with embeds and local assets, serve this folder with a local static server.

## Structure
- `index.html` — portfolio content and embeds
- `styles.css` — responsive visual design system and motion
- `script.js` — reveal animations, Instagram embed processing and unified product carousel
- `assets/` — supplied project images, renders, thumbnails and résumé

## Design system
Palette: warm paper, ink, acid lime, electric blue and coral.
Typography: Satoshi display/body with responsive `clamp()` sizing.
Layout: editorial grid, generous spacing, outlined cards, responsive breakpoints.
Motion: section reveals, ticker, subtle hover interactions and product carousel; reduced-motion preferences are respected.

The page is generic and does not name a target employer. Existing project and experience references are retained.
